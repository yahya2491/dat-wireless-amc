## Topic in one paragraph

Automatic Modulation Classification (AMC) is the task of identifying the modulation scheme of a received signal without prior knowledge of its parameters. It sits between signal detection and demodulation, and underpins applications in cognitive radio, spectrum monitoring, and electronic warfare. The report surveys the problem space and walks through classification approaches in depth. See the [PDF](AMC.pdf) for the full treatment.
